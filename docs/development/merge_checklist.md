# マージ前チェックリスト

変更に関係する項目を確認します。該当しない項目や未確認の項目にはチェックを付けません。

## 共通

- [ ] Issueの完了要件を満たしている
- [ ] 変更内容に問題がなく、Issue範囲外の変更が含まれていない
- [ ] 必要なテスト・動作確認が成功している
- [ ] 既存機能への影響を確認した
- [ ] 仕様書と実装に矛盾がない
- [ ] 必要なドキュメントが更新されている
- [ ] 秘密情報・個人情報・権利上問題のある画像が含まれていない
- [ ] PRの差分をセルフレビューした

## 分析・調査を含む場合

- [ ] 入力データ、出典、対象範囲を記録した
- [ ] 前処理、分析条件、使用バージョンなど再現に必要な情報を記録した
- [ ] 結果だけでなく制約・未確認事項も記録した
