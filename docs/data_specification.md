# データ仕様書 — 画像収集・品質・メタデータ

- **版**：Draft v0.2
- **更新日**：2026-11-15
- **状態**：画像カテゴリと収集規模は確定、収集・品質・前処理条件は未確定

## 1. 目的

迷彩と背景の色彩特徴量を、後から再現・比較・追跡できる画像データセットとして整理します。

## 2. 画像構成【確定】

| 役割 | 分類 | 各分類の画像数 | 合計 |
|---|---:|---:|---:|
| 迷彩 | 9種類 | 1枚 | 9枚 |
| 背景 | 6タイプ × 2植生状態 | 3枚 | 36枚 |
| **合計** | | | **45枚** |

- 比較の組み合わせ：9 × 36 = **324組**
- 324組は**独立した観測数ではありません**。同じ迷彩画像や背景画像を再利用します。
- 迷彩ごとに1画像しかないため、同じ迷彩の撮影差はMVPでは評価できません。

## 3. 背景分類【確定】

### 3.1 背景タイプ

フィールド全体を森林・市街地などで分類せず、サバイバルゲームで実際に身を隠す場所の植生や背景を基準に分類します。市街地・建造物は今回のMVPでは対象外です。

| ID | 背景タイプ |
|---|---|
| BG01 | 笹・ササ藪 |
| BG02 | 低木・灌木の茂み |
| BG03 | 高草・ススキ |
| BG04 | シダ・低い下草 |
| BG05 | 木の根元・樹幹 |
| BG06 | ツル植物・絡み合った藪 |

### 3.2 植生状態

| 状態 | 定義 |
|---|---|
| `green` | 緑葉が多く、植生が繁茂している状態 |
| `dry` | 枯葉・枯草・茶色系の植生が目立つ状態 |

- `green` / `dry` は季節そのものではなく、画像に写っている植生状態を示します。
- 撮影年月日や季節は、別途メタデータとして記録します。
- 雨による濡れ具合を意味するWet / Dryとは区別します。
- すべての背景タイプで両状態を収集する計画ですが、画像の入手可能性と分類の妥当性はデータ収集時に確認します。

## 4. 迷彩パターン【確定】

| ID | 迷彩パターン | 分類 |
|---|---|---|
| CM01 | MultiCam Tropic | Green系 |
| CM02 | MultiCam Original | 汎用系 |
| CM03 | A-TACS FG | Green系 |
| CM04 | A-TACS AU | Dry系 |
| CM05 | Tiger Stripe（緑系） | Green系 |
| CM06 | Desert Tiger Stripe | Dry系 |
| CM07 | 陸上自衛隊迷彩2型 | 独立比較 |
| CM08 | OD（単色） | 単色比較 |
| CM09 | PenCott GreenZone | Green系 |

Green系・Dry系・汎用系などは分析用の分類であり、実測した性能評価ではありません。

### 4.1 採用時の注意

- MultiCam Aridは採用せず、MultiCam Originalを採用します。
- PenCott BadLandsは採用せず、PenCott GreenZoneを採用します。
- Tiger Stripeの具体的なバリエーションや製品は画像収集時に確定します。
- A-TACS FG / AUとFG-X / AU-Xを混同しないよう、画像の名称と出典を確認します。

### 4.2 選定方針

1. サバイバルゲームでの知名度や使用実績があるパターンを含める。
2. Green系・Dry系の両方を比較する。
3. 同系列の異なるバリエーションを比較する。
4. 日本の森林環境を想定した比較対象として陸上自衛隊迷彩2型を含める。
5. 模様のない比較対象としてOD単色を含める。
6. 色彩だけでなく、模様の形状や細かさの違いも考慮する。

ODと柄物の比較だけでは色彩や明暗などの条件も同時に異なるため、模様単独の効果や因果関係は断定しません。

## 5. 画像採用基準（提案・未確定）

### 迷彩画像

- 生地やパターンが十分な面積で見える画像
- 強い照明色、影、反射、フィルターを避ける
- 模様以外の背景、ロゴ、タグなどが多い場合はROIを切り出す
- パターンが再現できるよう元画像と切り抜き条件を記録する

### 背景画像

- 背景タイプと植生状態を代表する自然物が大部分を占める画像
- 空・人・建物など比較に不要な要素を極力除外する
- 同じ背景タイプ・植生状態の3枚は可能な限り独立した撮影シーンを用いる
- 撮影距離・光の条件・季節をできる範囲で記録する

### 共通

- 元画像の改変は最小限とし、加工履歴を残す
- 色彩比較の前に安易な自動色補正を適用しない
- ファイル形式・解像度・色空間・画像の破損を確認する
- 公開可能な画像かどうか、ライセンス条件を明記する

## 6. 画像メタデータ（提案スキーマ）

画像1枚につき1レコードを持つ `data/metadata.csv` を想定します。

| カラム | 型（案） | 説明 |
|---|---|---|
| `image_id` | string | 一意な画像ID |
| `role` | enum | `camouflage` / `background` |
| `category` | string | 迷彩パターン名、または背景タイプを示す互換用の分類値 |
| `background_type` | string / nullable | 背景タイプID（`BG01`〜`BG06`）。迷彩画像では空欄 |
| `vegetation_state` | enum / nullable | `green` / `dry`。迷彩画像では空欄 |
| `camouflage_family` | string / nullable | MultiCam、A-TACS、Tiger Stripeなどの系列。背景画像では空欄 |
| `camouflage_variant` | string / nullable | Tropic、Original、FG、AUなどのバリエーション。背景画像では空欄 |
| `file_path` | string | ローカルの画像ファイル位置 |
| `source_url` | string / nullable | 出典URL（自撮りなら空欄可） |
| `license` | string | 利用・再配布条件 |
| `photographer` | string / nullable | 出典・撮影者名 |
| `capture_date` | date / nullable | 撮影年月日。取得できない場合は空欄 |
| `field_site_name` | string / nullable | 撮影フィールド・場所の名称。公開可否に配慮する |
| `capture_conditions` | string / nullable | 光・撮影距離・季節など |
| `crop_notes` | string / nullable | 対象領域と切り出し方法 |
| `notes` | string / nullable | 品質上の注意点など |

実運用前に必須カラム、命名規則、保存先を決定します。

## 7. ファイル配置（案）

```text
data/
├── raw/
│   ├── camouflage/
│   └── backgrounds/
├── metadata.csv
└── processed/
```

`raw/` は原本、`processed/` は切り抜き・変換後を想定します。著作権や容量の都合で、元画像をGit管理せず、取得手順とメタデータだけを公開する選択肢もあります。

## 8. 画像を比較する際の単位

- **画像単位**：各画像から色彩やテクスチャの特徴量を1セット抽出
- **ペア単位**：迷彩1枚 × 背景1枚を組み合わせて距離を算出
- **背景タイプ・植生状態単位**：各組み合わせに属する3枚について集計
- **背景タイプ単位**：必要に応じて `green` / `dry` を区別したまま比較する

背景タイプと植生状態を識別できる設計は確定していますが、3枚の集計方法と順位付けルールは未決定です。
