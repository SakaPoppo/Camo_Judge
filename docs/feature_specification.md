## 1. 分析対象

サバイバルゲームで実際に身を隠す自然環境の画像から、色彩・明暗・模様を特徴量として抽出し、迷彩画像との間で比較します。市街地・建造物は今回のMVPでは対象外です。

**今回のMVPの研究の問い（RQ1）**：背景環境ごとに、色彩的な類似度が最も高い迷彩柄は何か？

画像特徴量は**人間の視認性を直接測定したものではありません**。発見時間との関係はWebクイズで実測してから検証します。

### 1.1 比較構成【確定】

- 迷彩：9種類 × 各1枚 = 9枚
- 背景：6タイプ × `green` / `dry` × 各3枚 = 36枚
- 合計：45枚
- ペア比較：9 × 36 = 324組

各背景画像は `background_type` と `vegetation_state` を持ちます。比較結果は背景画像単位で保持し、背景タイプと植生状態を区別して集計できる設計にします。3枚の集計方法は未決定です。

## 2. 特徴量一覧（提案）

| グループ | 特徴量候補 | 算出方法の案 | 解釈 | v0.1案 |
|---|---|---|---|---|
| 色彩 | HSV色分布距離 | 正規化ヒストグラム + Bhattacharyya距離 | 小さいほど色分布が類似 | **中心指標候補** |
| 色彩 | 主要色5色＋構成比 | K-Meansで代表色を推定 | 画像の色の傾向を説明 | 候補 |

| 明暗 | 平均明度差 | LabのL*の平均値の絶対差 | 小さいほど平均明度が近い | 候補 |
| 明暗 | 明度ばらつきの差 | L*標準偏差の絶対差 | 小さいほど明暗の変動量が近い | 候補 |

## 3. 計算仕様の候補

### 3.1 HSV色分布距離

- RGB画像をHSVに変換する。
- H（色相）、S（彩度）の二次元ヒストグラムを作る。
- ヒストグラムを合計1に正規化する。
- `cv2.compareHist(..., cv2.HISTCMP_BHATTACHARYYA)` で距離を求める。
- 0に近いほど分布が近く、1に近いほど異なる。

**未決定**：ビン数、低彩度画素の扱い、ROI、リサイズ方法、色空間変換ライブラリ。

### 3.2 主要色

- K-Meansで代表色を5クラスタに分け、各色の構成比を算出する案。
- 見た目を説明するパレットとして可視化する。

**未決定**：色空間、サンプリング量、乱数固定、クラスタ数5の妥当性。

### 3.3 明度

- Lab色空間のL*（概ね0〜100）を使う。
- 平均L*と標準偏差を画像ごとに算出する。
- 各ペアの平均値差と標準偏差差を算出する。

**実装上の注意**：OpenCVの8ビットLab表現と標準的なL*の値域を混同しないこと。例えば `skimage.color.rgb2lab` を使う場合は入力RGBの範囲を正しく管理する。

### 3.4 代表色の色差（ΔE00）

- 画像全体の平均Lab色を代表色として、CIEDE2000色差を計算する案。
- 画像の多色性や模様は十分に反映しないため、**補助指標**として扱う。

### 3.5 エッジ密度（模様）

- 固定した前処理・しきい値でCannyエッジを抽出する案。
- エッジ画素数 / ROI内画素数を求め、背景と迷彩の差を比較する。
- 数値が近くても発見されにくいとは限らない。

**未決定**：縮尺・撮影距離をどう統一するか。背景遠景と布の接写の比較は解釈が困難なため、MVPの模様評価の採用は慎重に決める。

## 4. ペア比較データ（提案）

PostgreSQLを主データ管理とし、`outputs/results.csv` は分析結果の確認・共有用エクスポート形式として、以下のような内容を想定します。

| カラム | 内容 |
|---|---|
| `camouflage_id` | 迷彩画像ID |
| `background_id` | 背景画像ID |
| `camouflage_family` | 迷彩の系列 |
| `camouflage_variant` | 迷彩のバリエーション |
| `background_type` | 背景タイプID（`BG01`〜`BG06`） |
| `vegetation_state` | 植生状態（`green` / `dry`） |
| `hsv_distance` | HSV色分布距離 |
| `mean_lightness_diff` | 平均L*差 |
| `std_lightness_diff` | L*標準偏差の差 |
| `mean_color_delta_e00` | 平均色間のΔE00 |
| `edge_density_diff` | エッジ密度差（採用時のみ） |

採用しない特徴量のカラムは出力しません。単位・丸め・欠損の扱いは実装時に明記します。

将来、分析結果をDBへ保存する場合は、`images` の画像IDと、分析に使用した `image_files` の加工済みファイルIDを追跡できるようにします。分析結果テーブル、ID参照方法、正式なカラム名・型は未決定です。

## 6. 評価・解釈上の注意

- 各背景タイプ・植生状態の3枚について値とばらつきを示し、単一の画像での順位を一般化しない。
- 324ペアを独立な324例として統計検定しない。
- `green` / `dry` は画像の植生状態であり、季節や雨による濡れ具合として解釈しない。
- 指標の違いを不用意に一つの「総合迷彩性能スコア」に合成しない。
- 迷彩柄の有効性、発見時間、実際の隠蔽性能を画像特徴量だけで断定しない。
- 将来のWebクイズで得た人間の視覚評価を用いて、各指標の有用性を検証する。
