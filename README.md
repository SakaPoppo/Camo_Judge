# Camo Analysis（仮称）

> **状態：企画・仕様検討中（2026-11-15時点）**
>
> このリポジトリは、迷彩柄と背景環境の画像特徴量を比較するデータ分析プロジェクトです。現時点で実装・画像収集・分析は未着手です。

## プロジェクト概要

**研究目的（確定）**  
植生や背景環境によって、どの迷彩柄が人間に発見されにくいかを推定する。

**全体の研究の問い（確定）**  
背景環境と迷彩柄の色彩的な類似性は、人間による発見のしにくさに関係するのか？

**今回のMVP（確定）**  
画像解析によって、背景環境と迷彩柄の**色彩的な類似性**を定量化・可視化する。人間による発見のしにくさそのものは、この段階では測定しない。

**今後の拡張方針（確定）**  
Webクイズで人間の発見時間・正答率を収集し、画像特徴量との関係を検証する。

## 研究対象（確定）

- サバイバルゲームで実際に身を隠す自然環境を対象とする。
- フィールド全体を森林・市街地などで分類せず、実際の隠蔽場所の植生や背景を基準に分類する。
- 市街地・建造物は今回のMVPでは対象外とする。
- 背景の色彩・明暗・模様を画像特徴量として比較する。
- 人間からの発見されにくさは今回のMVPでは測定せず、将来のWebクイズで検証する。

## 研究の問い

- **RQ1（今回のMVP・確定）**：背景環境ごとに、色彩的な類似度が最も高い迷彩柄は何か？
- **RQ2（将来・確定）**：色彩的な類似度が高い迷彩柄ほど、人間に発見されにくいのか？

### 仮説（確定）

- **H1**：背景環境と色彩的に類似している迷彩柄ほど、人間による発見に時間がかかる。
- **H0**：背景環境と迷彩柄の色彩的な類似性は、人間による発見時間と関連しない。

> H1/H0の本格的な検証には、将来の人間の視覚評価データが必要です。今回のMVPの色彩比較結果のみから発見されにくさを断定しません。

| 迷彩画像 | 9種類 × 各1枚 = 9枚 | **確定** |

324組は画像同士の比較数であり、324件の独立した観測とは扱いません。同じ迷彩画像と背景画像を複数の比較で再利用します。

## 進め方（CRISP-DM）

1. **Business Understanding**：研究目的・RQ・仮説の定義 → **STEP 1確定**
2. **Data Understanding**：迷彩・背景カテゴリとデータ規模 → **カテゴリ選定完了**、画像収集・品質基準は未決定
3. **Data Preparation**：切り抜き、色空間変換、特徴量抽出
4. **Modeling**：各特徴量の距離を計算して比較（MVPでは機械学習を必須としない）
5. **Evaluation**：結果の妥当性・限界を確認し、考察を記録
6. **Deployment**：再現可能な分析コードと結果をGitHubへ公開
